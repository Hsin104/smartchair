請用這個指令啟動 Web，才能保留登入與本地設定：
flutter run -d chrome --dart-define=API_BASE_URL=https://sandbar-badass-subfloor.ngrok-free.dev

測試桌寵要跑桌面版：
PowerShell（以系統管理員身分進入）
cd C:\Users\DPZ\smart_chair_app
flutter run -d windows -t lib/desktop_pet_main.dart --dart-define=API_BASE_URL=https://sandbar-badass-subfloor.ngrok-free.dev

若要讓桌面桌寵和網頁使用同一個帳號資料，請用同一組帳密啟動桌寵：
flutter run -d windows -t lib/desktop_pet_main.dart --dart-define=API_BASE_URL=https://sandbar-badass-subfloor.ngrok-free.dev --dart-define=DESKTOP_USERNAME=你的帳號 --dart-define=DESKTOP_PASSWORD=你的密碼

關閉
Alt + F4
